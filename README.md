# Activity 1.5

## How to Make This Repository Private

This repository is currently **public**, which means anyone on the internet can see it. If you want to make it **private** so that only you and people you explicitly share it with can access it, follow these steps:

### Step-by-Step Instructions

1. **Navigate to your repository on GitHub**
   - Go to https://github.com/peachieqtie/Activity-1.5

2. **Access Repository Settings**
   - Click on the **Settings** tab (it's in the top menu bar of your repository)
   - Note: You must be the repository owner or have admin permissions to access this

3. **Scroll to the Danger Zone**
   - Scroll down to the bottom of the Settings page
   - You'll see a section called **"Danger Zone"** (usually with a red border)

4. **Change Visibility**
   - In the Danger Zone, look for **"Change repository visibility"**
   - Click the **"Change visibility"** button

5. **Select Private**
   - A modal/popup will appear asking you to confirm
   - Select **"Make private"**
   - You may need to type the repository name to confirm
   - Type: `peachieqtie/Activity-1.5`
   - Click **"I understand, change repository visibility"**

### What Happens When You Make It Private?

- ✅ Only you and collaborators you invite can see the repository
- ✅ Your code and files remain safe and secure
- ✅ You can still share access with specific people by inviting them as collaborators
- ❌ The repository will no longer appear in GitHub search results
- ❌ Other users won't be able to view or fork your repository

### Alternative: Using GitHub CLI (gh)

If you have GitHub CLI installed, you can also change visibility using this command:

```bash
gh repo edit peachieqtie/Activity-1.5 --visibility private
```
